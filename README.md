# Link pages

Link-in-bio pages for Forex with Fed, Fed Forex (YouTube) and Scrollvaanta, served by GitHub Pages.

- `forexwithfed/`: Forex with Fed, Instagram bio
- `fedforex/`: Fed Forex, YouTube channel
- `scrollvaanta/`: Scrollvaanta, Instagram bio

Edit a page's `index.html` (links) or `shared/links.css` (look), then push: GitHub Pages updates in about a minute.
Built on [LittleLink](https://github.com/sethcottle/littlelink) (MIT, see LICENSE-littlelink.md); icons from LittleLink.
